# Sarah — English speaking practice

Локальный тренажёр разговорного английского с голосовым преподавателем, живыми субтитрами и личным архивом занятий. Интерфейс на русском, практика на английском; объяснения можно попросить по-русски.

**Каждый пользователь запускает свою копию и подключает собственный Gemini API-ключ.** В репозитории нет ключей, разговоров, заметок или профиля автора. Это приложение для запуска на компьютере, а не общий сайт с аккаунтами.

## Быстрый запуск на Windows

1. Установите **Python 3.11 или новее** с [python.org](https://www.python.org/downloads/). При установке включите **Add Python to PATH**.
2. На GitHub нажмите **Code → Download ZIP**, распакуйте архив.
3. Создайте собственный ключ в [Google AI Studio](https://aistudio.google.com/apikey).
4. Запустите **run.bat**. Он создаст `.venv`, установит зависимости и попросит вставить ключ. При вводе ключ не отображается.
5. Откройте **http://127.0.0.1:8000** в Chrome или Edge. Оставьте окно сервера открытым во время занятия.

Для следующего запуска снова откройте `run.bat`. Существующий `.env` не перезаписывается. Смена ключа — редактированием этого локального файла и перезапуском приложения.

## Ручной запуск / macOS / Linux

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python configure.py
.venv/bin/python main.py --web
```

В Windows используйте `python` вместо `python3` и `.venv\Scripts\python.exe` вместо `.venv/bin/python`.

Альтернатива настройщику: скопируйте `.env.example` в `.env` и укажите свой `GEMINI_API_KEY`. Не отправляйте `.env` другим людям.

## Как заниматься

- **Начать разговор** — разрешите микрофон; сфера реагирует на голос, речь отображается текстом.
- Говорите без спешки и делайте паузы. Нажмите **Отправить**, когда закончите мысль.
- Sarah отвечает голосом и текстом. Начните говорить, чтобы перебить, или нажмите **Перебить**.
- Можно задавать вопросы по-русски. **Написать текстом** до начала разговора включает режим без микрофона.
- Цель по умолчанию **B1+**; в настройках доступны A2, B1, B1+, B2 и C1. Это цель практики, а не оценка знаний.
- Справа появляются исправления, варианты формулировок и полезные фразы.
- После **Завершить** дождитесь подтверждения сохранения.

В наушниках выключите настройку «Я слушаю через колонки» для более чувствительного перебивания. Распознавание зависит от микрофона, шума и доступности Google API.

## Заметки и память

С нуля архив пуст. Новые занятия сохраняются в локальную папку `notes/`: диалог, показанные исправления и итоговый конспект. Исходный текст записывается до запроса конспекта — при сбое генерации он остаётся на диске.

В **Моих занятиях** доступны поиск, чтение конспектов, скачивание Markdown и **Повторение** исправлений. Удаление перемещает заметку в `.sarah-trash` внутри папки записей; вкладка **Корзина** позволяет восстановить её. Такие записи не входят в контекст новых занятий.

Sarah получает извлечённый контекст последних четырёх занятий. Для Obsidian укажите в `.env` папку **своего** хранилища:

```dotenv
OBSIDIAN_NOTES_DIR=/absolute/path/to/your/vault/English
```

На Windows можно использовать путь с прямыми слешами, например `D:/MyVault/English`. Obsidian необязателен: приложение работает с обычными Markdown-файлами.

## API и данные

- Ключ хранится в локальном `.env`, читается Python-сервером и не передаётся в браузер.
- Аудио и текст отправляются в Google Gemini для ответов и распознавания; текст диалога — для конспекта и разбора. Выдержки из прошлых записей также входят в контекст модели.
- Ответы, распознавание и текстовый разбор используют API вашего Google-проекта. Доступ к моделям, квоты и стоимость зависят от проекта; подписка на пользовательское приложение не заменяет API-ключ.
- Модели задаются через `GEMINI_LIVE_MODEL`, `GEMINI_TRANSCRIBE_MODEL` и `GEMINI_SUMMARY_MODEL`. При ошибке доступа проверьте их доступность для своего ключа. Для текстового разбора предусмотрены резервные модели.
- Интерфейс загружает DM Sans и Geist через Google Fonts; без них использует системные шрифты.
- Сервер предназначен для личного локального использования на `127.0.0.1`. Не выставляйте его в публичную сеть: в приложении нет авторизации пользователей.

`.gitignore` исключает `.env`, локальные заметки, корзину, логи, аудио и скриншоты. Если выбрана своя папка заметок внутри репозитория, добавьте её в `.gitignore` перед отправкой изменений.

## Если не запускается

- **Нет ключа / ошибка доступа:** проверьте `.env`, настройки моделей и квоты Google-проекта; перезапустите сервер.
- **Порт занят:** завершите ранее запущенный сервер либо задайте `WEB_PORT=8001` и откройте соответствующий адрес.
- **Нет микрофона:** разрешите доступ для localhost или выберите текстовый режим.
- **Нет подтверждения сохранения:** скачайте текущий диалог через кнопку истории до перезагрузки страницы.

## Разработка

```sh
python -m pip install -r requirements-dev.txt
python -m unittest -q test_studio test_revision
node test_audio.cjs
node --check static/studio.js
node --check static/learning.js
```

Тесты используют временные заметки и подставные ответы, без настоящих API-запросов. Node.js нужен только для проверки JavaScript. Основной стек: Python, FastAPI, Google GenAI SDK, Web Audio и обычный JavaScript. Сборка фронтенда не нужна.
